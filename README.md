# Homebrew Tap for chinamedscheck-cli (chinamedscheck.com)

Official Homebrew tap for **[chinamedscheck.com](https://chinamedscheck.com)** command-line tools.

## Installation

```bash
brew tap AbigailDavised/chinamedscheck
brew install chinamedscheck-cli
```

## Quick Test

```bash
chinamedscheck-cli --help
```

# ChinaMedsCheck — China NMPA Drug Registry & Customs Medication Compliance Engine

Production command-line utility and Model Context Protocol (MCP) toolset for **[chinamedscheck.com](https://chinamedscheck.com)**. Validates China National Medical Products Administration (NMPA) approval codes, personal prescription drug import allowances (7 to 30 days personal-use rule), and bilingual OTC brand cross-references.
